Applications are open: inside Source Code Accelerator

Source Code Accelerator is a free, seven-week online program for software developers in Iraq who want to build with AI, and judge it, well. Applications close on 15 November.

Re:Coded teamNews20 October 20264 min read

Most AI courses sell the hype. They show you how to get a model to write code faster, then leave you to work out whether that code is any good, safe to ship, or solving the right problem. Source Code Accelerator starts from the other end. We teach the judgement first, then the tools.

Applications open today, 20 October 2026.

Who it’s for

Source Code Accelerator is for software developers in Iraq aged 18 to 35. You don’t need to be an AI expert. You do need to write code already, and to be curious about what your job looks like when a model can write some of it for you.

The program is free and taught in English. It runs fully online, with one live session on Zoom each week and work you can fit around a job or your studies.

What you’ll learn

The curriculum runs over eight topics in two halves. The first half is about how you think and work. The second is about how you build.

  1. 01Presence, purpose and the world ahead.Where software work is heading, and where you want to stand in it.
  2. 02Writing, feedback and working with others.Clear writing is now a technical skill. Prompts, specs and code reviews all depend on it.
  3. 03Problem framing and systems thinking.Defining the problem before reaching for a solution, and seeing what a change does downstream.
  4. 04AI risks and ethics.Bias, privacy, failure modes and who carries the cost when a system gets it wrong.
  5. 05AI for good and open models.What open models make possible, especially for teams without big budgets.
  6. 06Agentic development.Working with AI agents that plan and act, and keeping a human in charge of them.
  7. 07Code review, trust and security.Reading generated code critically, and knowing when not to trust it.
  8. 08Building and evaluating with models.Shipping something real, and measuring whether it works.

Sessions are led by industry practitioners, with guest speakers who build and deploy AI systems for a living.

Why we built it

For nearly ten years we ran coding bootcamps. They worked: 87% of our graduates found jobs. Then AI changed what a junior developer is hired to do. Writing code became the easy part. Knowing what to build, checking what a model produces and taking responsibility for it became the hard part.

Writing code became the easy part. Knowing what to build became the hard part.

We built Source Code Accelerator around that hard part. We’re not trying to turn developers into prompt engineers. We want people who can frame a problem, spot a risk, review a model’s work and explain their decisions to a team. Those are the skills that hold their value as the tools keep changing.

How to apply

It’s a short online form. Apply for Source Code Accelerator by 15 November 2026. You’ll hear back on 18 November.

Questions? See the FAQ on the Source Code Accelerator page or email ali@re-coded.com.
